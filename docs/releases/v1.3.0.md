## HunterPie Analytics 1.3.0

**The dashboard now speaks Japanese.** Settings → Display → 言語 (or open the app
with `?lang=ja`). It defaults to your browser's language and remembers the
choice; numbers, dates and durations follow it, and open charts/tables re-render
the moment you switch.

**Terminology comes from the game, not a translator.** Monster and skill/buff
names are generated from the game's own Japanese text, so they match the quest
results screen. The 30 quest-end awards are a **literal first pass** — if you
play in Japanese, please tell us any that differ from the in-game wording; the
review sheet is `docs/i18n/japanese-review.md` in the repo and corrections will
land in a 1.3.x patch. Weapon model names and player names stay exactly as
recorded.

**Search your hunts.** The Hunts tab and the hunt manager have a search box:
hunt number (`#1234`), hunter, monster, quest, date (`2026/11/03`) or result —
it matches Japanese and English names alike.

**Buff uptime now ends with the fight, not the results screen.** The companion
writes its quest clock at the results screen, which could inflate the uptime
denominator by minutes; the buff window now ends at the party's last hit (and
still covers every recorded activation). Failed hunts keep the in-game timer.

**Older companion dumps are repaired on re-import** — previously-unknown quest
targets get their identity filled in, so the "Only quest objectives" filter
works retroactively instead of hiding the wrong hunts.

**Ingest fix:** a source/dev or WSL run now also finds the companion that ships
with the installer (and the bundled layout inside Proton prefixes), so hunts are
no longer recorded as mod-only with the Buffs tab empty.

Bundles **HuntDumper 0.12.7** — no mod update needed if you are already on it.

## Which file do I need?

| File | What it's for |
|------|---------------|
| **`HunterPieAnalytics-Setup-*.exe`** | **Start here (Windows).** One-click install (per-user, no admin): the dashboard, the HunterPie companion, and the REFramework mod. Updating from the app also updates the companion. |
| **`HunterPieAnalytics-linux-*.tar.gz`** | **Linux / Steam Deck** (x86_64, glibc 2.35+). Dashboard with mod-only capture; extract and run, no Python needed. |
| **`HunterPieAnalytics-Companion-Proton.zip`** | The companion alone (self-contained) for Linux/Proton, if you want damage curves and buffs. |
| **`HuntDumper-*.zip`** | The in-game REFramework mod (also on Nexus). Needs REFramework. |
| **`SHA256SUMS.txt`** | Checksums for every download above. |

Already installed? **Settings → Check for updates** offers 1.3.0 in place (the
Windows Setup keeps your history and settings). The Linux tarball is built by
CI a few minutes after the release appears.

> The direct download is **unsigned**, so Windows SmartScreen may warn on first
> run — *More info → Run anyway*. Signing is in progress.

The in-app language switch is a UI preference only: the HunterPie companion
keeps its own language setting, and the game keeps its own.
